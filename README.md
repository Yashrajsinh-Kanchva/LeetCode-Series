## About The Project

This repository is a structured collection of LeetCode problem solutions, written while practicing Data Structures & Algorithms. It documents a DSA preparation journey — covering concepts from basics to advanced — along with optimized approaches and clean implementations.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Goal

* Strengthen problem-solving skills
* Prepare for coding interviews
* Master Data Structures & Algorithms
* Track daily consistency

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Topics Covered

**Basics**
* Arrays
* Strings
* Math Problems

**Intermediate**
* Recursion
* Binary Search
* Sorting
* Hashing

**Data Structures**
* Linked List
* Stack
* Queue
* Trees
* Binary Search Tree
* Heap / Priority Queue

**Advanced**
* Dynamic Programming
* Graph Algorithms
* Backtracking
* Greedy Algorithms

## How to Use

1. Open the relevant topic folder (`Easy`, `Medium`, or `Hard`)
2. Select a problem
3. Read the approach explained in the code comments
4. Run the code locally to see it in action
5. Try solving it yourself before checking the solution

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Why This Repository

Instead of randomly solving problems, this repository follows a topic-wise learning path, which helps with:
* Better concept retention
* Faster interview preparation
* Pattern recognition across problems
